# Etherscan service labels (labeling rule, step 2)

Every address that funded at least 50 LayerZero interactors (`sp.ETHERSCAN_MIN_FANOUT`) and is not
covered by the public label datasets (step 1) was looked up on etherscan.io. It is labeled
(`labeled = True`) if its Etherscan name tag identifies a shared service: an exchange hot wallet, a
bridge, solver or relayer, a protocol contract, or another named service. Exchange deposit addresses
(one customer's account), personal ENS names and untagged addresses are not labeled. Sybil labels
were not used.

`service_labels.csv` holds the 36 addresses in the rule's scope (10 labeled). It is the
`in_rule_scope` subset of `etherscan_lookups.csv` (this folder), which also lists the other addresses
looked up during the review and has the same columns:

| Column | Meaning |
|---|---|
| `address` | lower-case address |
| `etherscan_url` | page the tag was read from |
| `checked_on` | date the page was read (tags can change later) |
| `lookup_reason` | `hand_added_2024`, `top30_unlabeled_funder` or `funder_50_plus` |
| `address_kind` | `account` or `contract`, as shown by Etherscan |
| `name_tag` | Etherscan public name tag (empty if none) |
| `tag_badges` | Etherscan label badges, `;`-separated |
| `entity_type` | `exchange_hot_wallet`, `exchange_deposit`, `bridge_or_relayer`, `protocol_contract`, `other_service`, `personal_name` or `none` |
| `interactors_funded` | LayerZero interactors whose gas provider is this address (filtered network) |
| `covered_by_public_list` | already labeled by step 1 |
| `in_rule_scope` | `interactors_funded >= 50` and not covered by step 1 |
| `labeled` | the rule's decision |
| `decision_reason` | `public_list`, `shared_service_tag`, `exchange_deposit`, `personal_name`, `no_entity_tag` or `below_threshold` |

Each tag was matched to its address through the address printed on the Etherscan page, not through
the link that was opened. Both files are generated by `build_etherscan_lookups.py` (this folder; run from the repo root),
which also asserts that every address in the rule's scope was looked up.
