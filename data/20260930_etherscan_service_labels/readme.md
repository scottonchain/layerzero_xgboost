# Etherscan service labels (labeling rule, step 2)

Every address that funded at least 50 LayerZero interactors and is not covered by the public label
datasets was looked up on etherscan.io. It is labeled (`label = True`) if its Etherscan name tag
identifies a shared service: an exchange hot wallet, bridge, solver, relayer, or protocol
contract. Exchange deposit addresses (one customer's account), personal ENS names, and untagged
addresses are not labeled. Sybil labels were not used.

Tags were read from each address's Etherscan page on 2026-09-30 and 2026-10-01 by the authors and
recorded in `review_support/etherscan_tags_*.csv`. This file is generated by
`review_support/build_etherscan_service_labels.py`.
